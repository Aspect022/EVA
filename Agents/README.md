# Agents

This folder contains the AI Specialist Agents and their associated skills for the EVA project.

## Overview
Based on the Antigravity Kit architecture, these agents provide specialized capabilities across various domains.

## Agent Types
Refer to the `.agent/ARCHITECTURE.md` for a full list of specialist agents, including:
- Orchestrator
- Project Planner
- Frontend Specialist
- Backend Specialist
- and others...

## Skills
Skills are modular knowledge domains loaded on-demand by agents.
